Tres etapas, una progresión continua

Entendé cómo funcionan los contenedores desde el kernel. Namespaces, cgroups, overlayfs, imágenes, volúmenes y redes. La base que todo profesional DevOps necesita dominar.

Nivel 0: Introducción Nivel 1: Internals Nivel 2: Arquitectura Nivel 3: Imágenes Nivel 4: Contenedores Nivel 5: Dockerfile Nivel 6: Build Pro Nivel 7: Volúmenes Nivel 8: Redes Nivel 9: Registry

Coordiná múltiples contenedores como una sola aplicación. Aprendé a modelar stacks completos en YAML: servicios, redes, volúmenes, secrets y configuraciones.

Nivel 10: Introducción Nivel 11: docker-compose.yml Nivel 12: Multicontenedor Nivel 13: Networking Nivel 14: Proyecto

El salto a orquestación distribuida. Arquitectura completa de K8s, Pods, Deployments, Services, Ingress, PersistentVolumes, autoscaling y rolling updates.
